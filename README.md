# Summit Pixel Website

This is the static website for **Summit Pixel**, deployed via GitHub Pages.

## Features
- Packages with Stripe payment links
- Contact form via Formspree
- Responsive design with CSS

## Deployment
1. Push all files to your GitHub repo: `summit-pixel`
2. Enable GitHub Pages in repo settings (choose branch: `main` → root).
3. Your site will be live at: `https://UmaiRice.github.io/summit-pixel/`

Enjoy 🚀
